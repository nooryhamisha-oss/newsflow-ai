# NewsFlow AI — اتاق خبر دیجیتال

خبرنگار فقط **ویدیو را آپلود می‌کند**؛ هیچ دستور (پرامپت) نمی‌نویسد. سیستم خودکار:

1. به **صدای** ویدیو گوش می‌دهد و محتوا را تحلیل می‌کند (متن کامل ساخته یا نمایش داده نمی‌شود)
2. برای سه زبان **دری، پښتو و English** می‌سازد:
   ۳ تیتر پیشنهادی، کپشن اینستاگرام / X / فیسبوک / تلگرام، و هشتگ
3. **بهترین بخش خبر** را پیدا می‌کند و با **صدای اصلی** برش می‌دهد
4. **لوگوی شما** را روی کلیپ می‌گذارد و سه قالب می‌سازد:
   عمودی ۹:۱۶ (ریلز/تیک‌تاک/استوری)، مربع ۱:۱، افقی ۱۶:۹ — هر کدام با دکمهٔ دانلود

## پیش‌نیازها
- Node.js ‏18.18 یا بالاتر
- FFmpeg (دستور `ffmpeg -version` باید کار کند)
  - ویندوز: `winget install ffmpeg` — مک: `brew install ffmpeg` — لینوکس: `sudo apt install ffmpeg`
- کلید API رایگان Gemini از https://aistudio.google.com/apikey

## اجرا
```bash
npm install
cp .env.example .env      # کلید GEMINI_API_KEY را داخل .env بگذارید (ویندوز: copy .env.example .env)
npm run dev               # سایت: http://localhost:5173
```
اگر FFmpeg نصب نباشد یا کلید تنظیم نشده باشد، بالای صفحه یک اعلان نشان داده می‌شود.

## انتشار (production)
```bash
npm run build
npm start                 # همه‌چیز روی http://localhost:3001
```
برای ذخیرهٔ ماندگار فایل‌ها روی Railway/Render، متغیر `STORAGE_DIR` را به مسیر یک Volume بدهید.

## ساختار پروژه
```
server/   config.js  تنظیمات   · media.js  FFmpeg   · ai.js  Gemini و اعتبارسنجی خروجی
          jobs.js    ذخیرهٔ کارها و صف · pipeline.js  مراحل پردازش · index.js  API
src/      App.jsx · components/ (هر بخش صفحه) · lib/ (api، ثابت‌ها، ابزارها) · styles.css
```

## نکته‌ها
- لوگو را یک‌بار آپلود کنید؛ روی همهٔ کلیپ‌های بعدی می‌آید.
- کارها یکی‌یکی پردازش می‌شوند (صف) تا سرور زیر بار FFmpeg نیفتد؛ می‌توانید چند ویدیو پشت سر هم بفرستید.
- تحلیل از روی صدا انجام می‌شود. کیفیت پښتو و دری به وضوح صدا بستگی دارد؛ قبل از انتشار، تیترها و کپشن‌ها (مخصوصاً نام‌ها و عددها) را مرور کنید.
- حداکثر طول ویدیو برای تحلیل حدود ۷۵ دقیقه است (سقف حجم درخواست Gemini). محدودیت حجم آپلود پیش‌فرض ۵۰ مگابایت است (`MAX_UPLOAD_MB`).
- فایل‌ها خودکار پاک نمی‌شوند؛ از دکمهٔ حذف در «کارهای اخیر» استفاده کنید.
- این برنامه ورود/رمز ندارد. اگر روی اینترنت منتشر می‌کنید، حتماً پشت رمز (مثلاً Basic Auth در Nginx/Cloudflare Access) قرار دهید، وگرنه هر کسی می‌تواند از سهمیهٔ Gemini شما استفاده کند.
- روی Bolt/StackBlitz اجرا نمی‌شود (FFmpeg و سرور لازم است). روی کامپیوتر خودتان یا Railway، Render یا VPS اجرا کنید.
